| Исходное состояние | Переходное состояние | Событие |
| :--- | :--- | :--- |
| `START` | `PAYMENT_CREATED` | **PaymentInitiated**. Пользователь нажал «Оплатить». Система создала запись о транзакции. |
| `PAYMENT_CREATED` | `FUNDS_RESERVED` | **FundsReserved**. Успешное списание (холдирование) средств со счета клиента. |
| `PAYMENT_CREATED` | `FAILED` | **InsufficientFunds / AccountBlocked**. Ошибка при списании средств (недостаточно средств, счет заморожен и т.д.). Процесс завершается, компенсация не требуется. |
| `FUNDS_RESERVED` | `CHECKING` | **FraudCheckStarted**. Транзакция отправлена в антифрод-систему на первичный автоматический анализ. |
| `CHECKING` | `AUTHORIZED` | **FraudCheckApproved**. Антифрод-система вернула статус «Разрешение». Деньги готовы к переводу контрагенту. |
| `CHECKING` | `DECLINED` | **FraudCheckDeclined**. Антифрод-система вернула статус «Запрет». Необходимо инициировать возврат холдированных средств клиенту (RELEASE). |
| `CHECKING` | `PENDING_MANUAL_REVIEW` | **ManualReviewRequired**. Антифрод-система не смогла принять решение автоматически и отправила транзакцию на ручную проверку оператору. Запускается таймер ожидания (20 мин). |
| `PENDING_MANUAL_REVIEW` | `AUTHORIZED` | **ManualReviewApproved**. Оператор безопасности подтвердил легитимность транзакции в ходе ручной проверки. |
| `PENDING_MANUAL_REVIEW` | `DECLINED` | **ManualReviewDeclined**. Оператор безопасности отклонил транзакцию по результатам анализа. |
| `PENDING_MANUAL_REVIEW` | `AUTHORIZED` | **CutOffTimeReached**. Истек лимит времени ожидания (20 мин). Система автоматически разрешает транзакцию в соответствии с политикой "default allow on timeout". |
| `AUTHORIZED` | `SETTLED` | **SettlementCompleted**. Перевод денег контрагенту (EXECUTE) успешно проведен через платежный шлюз. Транзакция финализирована как успешная. |
| `AUTHORIZED` | `FAILED` | **SettlementFailed**. Технический сбой или отказ банка-эквайера при попытке перевода средств контрагенту. Требуется возврат холдированных средств (RELEASE), так как `EXECUTE` не прошла. |
| `DECLINED` | `REFUNDING` | **ReleaseInitiated**. Запуск компенсационной транзакции по разблокировке средств обратно на счет клиента. |
| `FAILED` (при статусе `FUNDS_RESERVED` или `AUTHORIZED`) | `REFUNDING` | **ReleaseOnFailure**. Транзакция завершилась ошибкой после списания средств, необходим автоматический возврат денег клиенту. |
| `REFUNDING` | `CLOSED` | **RefundCompleted**. Возврат денег клиенту успешно завершен. Итоговый статус операции — отменена. |
| `SETTLED` | `COMPLETED` | **NotificationSent**. Финальное уведомление об успешном платеже отправлено клиенту (e-mail/push). Процесс завершен. |
| `CLOSED` | `TERMINATED` | **NotificationSent**. Уведомление об отмене платежа отправлено клиенту. Процесс завершен. |
| *Любое активное состояние* | `SUSPENDED` | **TechnicalErrorRetry**. Технический сбой сети или БД. Система переводит процесс в режим ожидания для автоматического восстановления (Retry / Incident Recovery). |
