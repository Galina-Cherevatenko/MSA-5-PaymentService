| Транзакция | Описание | Тип | Компенсация |
| :--- | :--- | :--- | :--- |
| `CREATE_PAYMENT` | Создание записи о платеже в БД со статусом `PENDING`. Фиксация суммы, валюты, участников и уникального ID транзакции. | Необратимая | Нет (логовая запись, отказ не откатываем) |
| `RESERVE_FUNDS` | Списание (холдирование) средств со счета клиента. Деньги блокируются для последующего перевода контрагенту. | Компенсируемая | `RELEASE_FUNDS` |
| `RUN_FRAUD_CHECK` | Запуск проверки в сервисе FraudCheck Service. Отправка данных транзакции и ожидание ответа (разрешение/запрет/ручная проверка). | Повторяемая (retry) | Нет (операция идемпотентна, компенсация логики происходит в `UNLOCK_FUNDS`) |
| `WAIT_MANUAL_REVIEW` | Ожидание решения оператора безопасности в течение 20 минут. Состояние сохраняется, процесс приостанавливается до получения сигнала или истечения таймера. | Повторяемая (ожидание) | Нет (в случае cut-off-time система сама выполняет положительное решение) |
| `EXECUTE_PAYMENT` | Перевод ранее зарезервированных средств на счет контрагента. Подтверждение клиринга с внешним платежным шлюзом. | Необратимая | `REFUND_PAYMENT` |
| `NOTIFY_USER` | Отправка клиенту уведомления (email/push) об успешном статусе операции. | Повторяемая | Нет |
| `REFUND_PAYMENT` | Компенсационная транзакция. Возврат денежных средств со счета контрагента обратно клиенту в случае пост-фрод анализа или ошибки клиринга после списания. | Необратимая (компенсирующее действие) | Нет |
| `RELEASE_FUNDS` | Компенсационная транзакция. Разблокировка (возврат) средств на счет клиента в случае, если платеж не прошел проверки (FraudCheck запретил операцию). | Необратимая (компенсирующее действие) | Нет |
| `MARK_AS_FAILED` | Обновление статуса транзакции как `FAILED` или `DECLINED` для финальной отчетности и систем аудита. | Повторяемая | Нет |
